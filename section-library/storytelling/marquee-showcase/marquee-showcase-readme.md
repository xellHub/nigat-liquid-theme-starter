# Marquee Showcase

A dynamic horizontal image marquee loop with a centered social community callout card.

## Purpose

Showcase high-energy brand lifestyle photography, customer UGC, or Instagram editorial imagery in a continuous infinite ribbon, anchored by an inviting central community hook ("Join the family / FOLLOW US").

## Physical composition

- **Marquee Track:** Full-bleed infinite horizontal marquee track looping seamless image tiles at customizable duration.
- **Center Callout Card:** Anchored central card with subtle side fade masks, displaying a two-tier headline (sans-serif + italic serif) and social profile link.
- **Hover Interactions:** Automatic marquee pause on cursor hover; individual image zoom.
