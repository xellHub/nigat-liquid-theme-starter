# Interactive Steps

An editorial section family for guiding customers through numbered routines, regimens, and multi-step methodologies.

## Purpose

Break down multi-step regimens (skincare, brewing, assembly, styling) into an intuitive two-column interactive experience where clicking a step reveals its details and dynamically updates the synchronized visual showcase.

## Physical composition

- Heading with dual typography support (modern sans-serif + italic serif emphasis).
- Two-column split layout (sticky showcase frame + interactive step accordion list).
- Pill thumbnail previews with active/inactive state handling.
- Direct category/product purchase CTAs.
