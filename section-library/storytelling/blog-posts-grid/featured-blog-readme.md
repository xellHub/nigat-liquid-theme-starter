# Featured blog

## Anatomy

A configurable editorial introduction paired with a resource carousel.
The starter heading keeps an `h2` semantic level but uses the shared `small` heading size, so it reads as a secondary homepage heading beneath larger story content.

## Responsive behavior

The section uses container-aware layout rules and collapses to a single logical reading order on narrow containers.

## Accessibility

Content preserves semantic landmarks, keyboard targets, visible focus, and theme-level reduced-motion behavior. Merchant-provided media must include meaningful alternative text when informative.
