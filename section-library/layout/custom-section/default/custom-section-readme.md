# Custom section

The template-eligible shell owns the page width, outer spacing, and color scheme. Child blocks own content and internal styling. On narrow viewports, media-with-text stacks through its own block stylesheet.

## Editor and accessibility

Use the named presets to create image/text, brand story, value props, newsletter, and logo layouts. Each heading, paragraph, image, logo, and action remains a child block. Set meaningful alternative text on every real logo and image. The shell excludes header and footer groups.

## Fork behavior

Colors, type, spacing, and radii inherit the semantic foundation tokens. Forks change identity in the token layer, then reuse this section and its blocks unchanged.
