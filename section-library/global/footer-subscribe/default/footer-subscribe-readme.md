# Footer subscribe

## Anatomy

Independent newsletter subscription banner configured for the footer group. Composed of an underlying media background container (`_footer-subscribe`) with configurable overlay and child theme blocks (`eyebrow`, `heading`, `text`, `newsletter-form`, `button`).

## Responsive behavior

The section provides full-width viewport coverage with fluid container-aware padding and clamp-based typography sizing. On smaller screens, form inputs and buttons stack vertically for optimal mobile ergonomics.

## Accessibility

Forms maintain visible labels, high-contrast states on dark media overlays, clear keyboard focus rings, and proper ARIA relationships for status feedback messages.
