# Featured collection

## Anatomy

A configurable collection heading paired with product browsing behavior.

## Responsive behavior

The section uses container-aware layout rules and collapses to a single logical reading order on narrow containers. Collection tabs and product cards scroll within their own width on small screens. Native swipe and horizontal trackpad gestures remain available; frosted edge arrows appear only where more content can be reached. Native horizontal scrollbars are hidden.

## Accessibility

Content preserves semantic landmarks, keyboard targets, visible focus, and theme-level reduced-motion behavior. Merchant-provided media must include meaningful alternative text when informative.
