# Slideshow Inset

A slideshow family using rounded inset slides with peeking adjacent cards and pill pagination.

## Purpose

Feature multiple high-priority campaigns or collection arrivals in a centered inset hero carousel where adjacent slides peek on the screen edges to provide clear forward/backward navigational momentum.

## Physical composition

Center-aligned cards with rounded corners, responsive side peeking, a two-column layout (text left, media right), and interactive bottom pill pagination.

## Psychology

Eliminates the hidden-slide blindspot of conventional carousels through peripheral edge peeking while keeping the active campaign isolated and focused.
