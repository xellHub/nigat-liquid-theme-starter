# Embla Carousel Slideshow

A full-frame touch- and drag-enabled hero slideshow with multiple backdrop modes and configurable indicator controls.

## Purpose

Deliver immersive, full-screen brand storytelling with fluid touch gesture support, flexible content positioning, backdrop glass/card styling, and modern navigation pagination styles.

## Physical composition

- **Full-Bleed Media Viewport:** Responsive `<picture>` elements supporting independent desktop and mobile crops with customizable dark overlays.
- **Backdrop Styling:** Supports `glass`, `glass_light`, `card`, `fade_horizontal`, `fade_bottom`, or `none`.
- **Reusable Header & CTA Integration:** Embedded `section-header` and dual action button hierarchy.
- **Controls & Pagination:** Supports `dots`, `lines` (with progress animations), `counter` (01 / 03), and `progress` pills, alongside floating chevron arrows or unified bottom control bars.

## Psychology

Full-screen imagery commands initial sensory capture. Providing tactile drag responsiveness alongside clear numerical or linear progress indicators reduces user impatience and sustains curiosity through multiple promotional slides.
