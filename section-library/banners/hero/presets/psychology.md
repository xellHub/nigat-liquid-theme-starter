# Hero Presets Psychology

Choose the editorial carousel when progressive exploration is useful: the main scene earns attention, concise copy establishes meaning, and the rail lets shoppers inspect adjacent stories without leaving the opening frame.

Choose gradient media copy when speed matters more than exploration. Its directional scrim creates a direct path from visual context to promise, supporting copy, and action.

Do not select the carousel merely to add motion, and do not select gradient media copy when several offers deserve equal weight. Preset choice should reflect the campaign's decision structure rather than decoration.
