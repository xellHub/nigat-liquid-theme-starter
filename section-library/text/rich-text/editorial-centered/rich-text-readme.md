# Rich Text — Editorial Centered

A constrained editorial layout for brand stories, announcements, and calls to action.

## Physical anatomy

The section provides a readable-width vertical flow. Merchants compose its content from eyebrow, heading, text, link, button, divider, spacer, and group blocks.

## Responsive behavior

The column remains fluid within the mobile gutter and caps its line length on larger screens. Direct children inherit the section's left or center alignment.

## Accessibility

Heading levels and link semantics are configured on their respective blocks. Focus treatment, contrast, typography, and colors come from the shared token system.
