# Collection List Editorial Psychology

Behavioral dynamics of the paired editorial sidebar with an interactive collection rail.

## Cognitive ergonomics

1. **Context-Led Discovery (Anchored Intro):**
   - Placing brand values and editorial context ("Natural self care products / We create safe products...") alongside category browsing frames the products with purpose and ethical reassurance before purchase evaluation begins.
2. **Paced Visual Rhythm:**
   - Separating the narrative from the inventory rail prevents visual overload. The user digests the premise on the left, then navigates distinct curated pillars on the right.
3. **Diagonal Arrow Affordance (`↗`):**
   - Micro-action buttons with diagonal departure arrows signal destination navigation and encourage exploration into specific collection catalog depths.
