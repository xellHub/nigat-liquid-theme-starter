# Collection List Editorial

An editorial collection-list family pairing a narrative sidebar intro with an interactive horizontal category rail.

## Purpose

Introduce an editorial narrative alongside a horizontal rail of curated collections, balancing contextual storytelling with product category exploration.

## Physical composition

A fixed or sticky left-hand narrative sidebar (eyebrow, heading, descriptive copy, and directional arrow controls) paired with a responsive right-hand horizontal scroll rail of elevated collection cards.

## Psychology

Frames collection browsing with merchant values and qualitative reassurance. Diagonal departure arrow indicators (`↗`) clearly communicate navigation into catalog taxonomy.
