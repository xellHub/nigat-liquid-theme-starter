# Collection List Carousel Psychology

Behavioral considerations and decision ergonomics for horizontal collection navigation.

## Cognitive ergonomics

1. **Choice Architecture & Chunking:**
   - Presenting collections in a curated horizontal rail prevents choice paralysis. Users focus on 3 primary category pillars while retaining the psychological affordance that deeper catalog variety is available.
2. **Superscript Count Micro-Cues (`Tops¹⁰`, `Accessories²²`):**
   - Displaying numeric item count as a subtle superscript provides quantitative inventory context without visual clutter. It signals depth and catalog freshness while maintaining high-end editorial aesthetics.
3. **Continuous Affordance (Mobile Peeking):**
   - By revealing 75-80% of a primary card and 20-25% of the adjacent card on mobile viewports, the interface instinctively communicates swipeability without requiring instruction.
4. **Editorial Typographic Contrast:**
   - Juxtaposing upright serif with cursive/italic keywords (`Our <em>special</em> collections`) creates warmth and high-fashion authority, transforming ordinary taxonomy into a curated exhibition.
