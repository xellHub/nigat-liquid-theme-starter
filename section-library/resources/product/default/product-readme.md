# Product

A layout-only product section containing one `_product-resource` composite. The resource block preserves gallery, zoom, sharing, wishlist, sticky-cart, modal, and structured-data behavior while its product-information children remain independently reorderable.

## Anatomy

```text
_product-resource
├── _product-vendor
├── _product-title
├── _product-price
├── _product-variant-picker
├── _product-quantity
├── _product-buy-buttons
├── _product-description
├── _product-payment-guarantee
├── _product-return-policy
└── _product-share
```

## Accessibility

Existing dialog, gallery, form, live-region, focus, and keyboard contracts are retained.
