# F12–F20 implementation and release checks

Code and local static checks are complete for F12–F20. The theme has not been exercised in a Shopify development store or the XellHub renderer during this pass. Treat the checks below as release gates before deploying a fork.

## Product page: F12–F14

- F12: The quantity block associates with the native product form by ID, and sticky add-to-cart calls `requestSubmit`. Dynamic checkout uses Shopify's `payment_button` filter. Variant changes update price, unit price, availability, quantity rule, URL and featured media; invalid combinations disable purchase. Media use Shopify's `media_tag` for non-images. The size chart uses a selected page and appears only when that page has content. Check deep links, unavailable combinations, alternate media, no media, zoom keyboard/focus, native quantity limits, dynamic checkout, and no-JavaScript purchase in both the full and quick-view product templates. [Shopify payment button](https://shopify.dev/docs/api/liquid/filters/payment_button), [media tag](https://shopify.dev/docs/api/liquid/filters/media_tag).
- F13: Accordion summaries render a static editable heading before JavaScript. The repository FAQ templates and presets moved their first heading into that slot. Product information presets bind description, selected page, `custom.care_instructions`, or `custom.ingredients`; empty sources hide their panel. Check summary keyboard behavior, long page content and metafield types in a real editor. Installed merchant FAQ JSON was not migrated; map its old first heading into static `trigger` before deployment.
- F14: Standard `reviews.rating` and `reviews.rating_count` metafields drive the summary. The empty product reviews composite accepts an app block without claiming reviews exist. Its summary becomes an anchor only when the review region contains child content. Configure a real review provider and verify its app block, rating scale/count, anchor, editor selection and empty state. Editorial testimonials are separate from product reviews. No review aggregate JSON-LD is fabricated; Shopify's actual product structured data remains server generated. [Rating object](https://shopify.dev/docs/api/liquid/objects/rating).

## Catalog and global chrome: F15–F17

- F15: The collection template now uses `_collection-banner`, `_collection-navigation` and `_catalog-results` in that order. The merchant selects a menu for subcategories. The banner H1 binds to the collection title; image and description bind to collection resources. Catalog cards use the F07 static slot. Desktop and mobile column controls reach the grid. Ajax filtering keeps prior results on a failed request and restores focus when an activated link disappears. Check collection media/no media, blank description, nested menu, price ranges, multiple filters, empty results, clear-all, back/forward, pagination and quick add after replacement.
- F16: Header menu links render three levels on desktop and mobile. Native details summaries toggle with Enter/Space; Escape and outside click close open desktop menus. A separately editable promotion matches a top-level menu by linked collection or page resource ID, never translated title. Verify long labels, parent destination links, keyboard-only navigation, account enabled/disabled states, sticky toggle and announcement-height changes. The mega promotion supports one configured collection or page destination per header instance.
- F17: The rotator has optional dismissal and pause/play controls with locale strings. Dismissal is stored for the browser session using section/block IDs plus a text-derived revision. Autoplay pauses on focus, hover, hidden tab, reduced motion and Theme Editor selection; timers are released on unload. No-JavaScript messages remain readable. Check dismiss/reload, edited message revision, keyboard controls, announcement offset, multiple messages and section re-render.

## Home and discovery: F18–F20

- F18: The canonical `custom-section` shell exposes image/text left and right, brand story, value props, newsletter/promo and logo-list presets using existing nested blocks. `index.json` is a six-section starter; the former 20-section composition is retained as `index.showcase.json` for reference. The video atom defers external frames, starts muted hosted autoplay only while visible and allowed by reduced-motion settings, and pauses hidden slides. Countdown now requires an explicit timezone-bearing expiry and releases its timer. Footer payment marks render only from actual enabled payment types. Check preset editor trees, media orientations, video controls/posters, newsletter submission, logo alt text, countdown expiry and footer resources.
- F19: The default product template uses the Shopify recommendations HTML endpoint with the current product ID, dynamic section ID, limit and related/complementary intent. The shell hides until nonempty distinct products return. The resource loop uses the F07 static product-card slot. A failed request leaves no blank heading. Check locale, both intents, zero results, section removal during fetch, editor preview, card actions and product context. [Product Recommendations API](https://shopify.dev/docs/api/ajax/reference/product-recommendations), [recommendations Liquid object](https://shopify.dev/docs/api/liquid/objects/recommendations).
- F20: The optional recently-viewed section loads Shopify's Customer Privacy API and checks `preferencesProcessingAllowed` before touching storage. History contains only handles/timestamps, caps at 12, expires after 30 days and excludes the current product. Up to three locale-aware product section requests resolve available products into the same F07 card slot. Blocked storage, no consent, no history or all failed requests leave the section hidden. Check A→B→A ordering, deleted/unpublished product, market switch, consent changes, storage exceptions and section removal during requests. Product templates without this optional section do not record views. [Customer Privacy API](https://shopify.dev/docs/api/customer-privacy), [Section Rendering API](https://shopify.dev/docs/api/ajax/section-rendering).

## Installed-theme migration

Repository JSON templates were migrated, but Shopify-hosted merchant template data was not inspected or changed. Before a fork is deployed, inventory installed product, collection, FAQ and homepage template data. Preserve customized headings, card children, menu choices, section order and review provider blocks when mapping to the new structures. The old homepage composition remains in `index.showcase.json`; replacing a merchant's live homepage requires a deliberate editor/data migration.
