# Foundational Theme — Must-Have Sections

Universal, vertical-agnostic sections every fork starts with. Each is a pure layout shell — arrangement settings only, content comes from blocks. Names are kebab-case, matching Liquid theme section file handles.

## Structure

- `header` — logo, nav, cart, search, account
- `mega-menu` — nested nav + promo tiles, lives inside header
- `announcement-bar` — top-of-page rotating message strip
- `footer` — links, newsletter, social, payment icons
- `breadcrumbs`
- `sidebar` — filters / secondary nav for collection & blog pages
- `back-to-top`

## Hero / Landing

- `hero` — full-width banner, media + heading + CTA
- `hero-split` — image one side, content the other
- `slideshow` — multiple hero slides

## Product & Commerce

- `featured-product` — single spotlighted product
- `featured-collection` — grid/carousel from one collection
- `collection-list` — grid of collection tiles
- `product-recommendations`
- `recently-viewed`
- `collection-grid` — product grid + filters/sort (collection template)
- `cart` / `cart-drawer`
- `free-shipping-bar`
- `search-results`

## Content

- `rich-text` — centered heading + text + button
- `image-with-text`
- `multi-column` — icon/image + heading + text grid
- `image-compare` — before/after slider
- `video`
- `blog-posts`
- `collapsible-content` — FAQ / accordion
- `tabs`
